# 4단계: spec 확정

인터뷰에서 정한 것을 사용자가 뜻대로 이해했는지 확인하고 확정을 받는다.

1. spec에 동작 표와 test할 seam을 채운다. 결정 표에서 동작을 끌어낸다. 형식은 `references/spec-format.md`를 따른다.
2. 설계 전체를 한 번 가르친다. 한 문단으로 먼저 말하고, 그림으로 보여 주고, 결정 목록으로 끝낸다. `grill-me` skill의 "가르치는 법"을 따른다.
3. 되돌리기 비싼 결정(`grill-me` skill의 "사실과 결정")마다 장면 하나로 결과를 확인한다. 누가 정했든 되돌리기 비싸면 확인한다. "이 결정이면 <장면>에서 <결과>가 됩니다. 원하는 결과가 맞나요?" 사용자가 뜻을 다르게 알고 동의한 결정을 여기서 잡는다.
4. 결정 목록을 번호(D1, D2, …)와 함께 보여 준다. 사용자가 답한 것, agent가 정한 것, 추천대로 정한 것을 구분한다.
5. test할 seam이 사용자의 기대와 맞는지 묻는다.
6. 사용자가 일부를 고치면 그 결정과 거기에 달린 결정만 다시 묻는다.

통과: 사용자가 확정한다고 말했다. spec의 상태를 "확정"과 날짜로 바꾼다. 설계까지만 원한 요청이면 spec 경로와 결정 수를 알리고 여기서 끝낸다.
