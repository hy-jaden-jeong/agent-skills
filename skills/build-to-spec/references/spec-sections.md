# build-to-spec이 spec에 더하는 절

spec의 나머지 절(문제부터 결정 표까지) 형식은 `<skills 폴더>/grill-me/references/spec-format.md`에 있다. 이 파일은 만들고 증명하는 동안 채우는 것만 적는다.

## 상태

- slice에 동의받으면 `상태: 구현 중 (YYYY-MM-DD)`, 검증을 마치면 `상태: 검증 끝 (YYYY-MM-DD)`으로 바꾼다.

## 동작 표의 증명 칸

`grill-me`가 비워 둔 "증명" 칸을 구현 단계에서 채운다. 돌린 명령과 본 결과를 쓴다. 어느 slice에서 증명했는지(S 번호)를 앞에 붙인다. test가 고치기 전에도 통과했으면 그렇게 적고 다른 증명(직접 본 출력)을 함께 적는다.

## 회귀 기준

이미 돌아가는 것을 바꾸는 일에만 둔다. 같은 폴더의 `golden-master.md`를 따른다.

```md
## 회귀 기준

- 대상: <결과물 위치와 수>
- 기준: <기준 commit 또는 사본 경로>, 두 번 구워 같음을 확인
- 굽기·견주기: <명령>
- 뺀 것: <매번 달라 뺀 것과 이유>
```

## slice

```md
## slice

| # | 만드는 것 | 채우는 동작 | 먼저 끝나야 하는 slice | 증명 방법 | 상태 |
| --- | --- | --- | --- | --- | --- |
| S1 | <이 slice가 끝나면 되는 일> | B1, B2 | 없음 | <돌릴 장면과 통과 조건> | 대기 / 진행 / 끝: <본 결과 요약> |
```

## 검증 기록

```md
## 검증 기록

<날짜. 누가 봤나(새 subagent 셋 / 만든 쪽).>

### 방향 1: spec / 방향 2: 규칙 / 방향 3: 깨뜨리기
- 고침: <발견과 고친 것>
- 그대로 둠: <발견과 이유>
- 범위 밖: <spec이 요구하지 않는 장면에서 본 것>

### 고친 뒤
- <다시 돌린 test, golden master 결과>
```
